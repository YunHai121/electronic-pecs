## 三、风险识别与应对控制策略

1. **儿童听觉超敏反应风险**：
   - *风险表现*：某些ASD儿童对合成机械音极度抗拒或产生惊恐情绪；
   - *控制策略*：系统在家长端提供“柔和慢速”模式（默认0.85x语速），支持音高微调，并在未来版本提供家长真人声音录制与回放功能。
2. **沉迷屏幕脱离现实交换风险**：
   - *风险表现*：电子设备容易让儿童误以为是“玩手机”，丧失与真人“眼神与身体递送”的交换本质；
   - *控制策略*：在系统启动界面与说明书中强化特教指导——必须保留“儿童拿着屏幕递给大人”或“家长听到发音后再行强化”的社交回路，不替代临床人际干预。
3. **数据丢失与家庭更换设备风险**：
   - *风险表现*：家长辛辛苦苦拍了几十张家常卡片，换手机时全部丢失；
   - *控制策略*：提供标准纯文本 JSON 离线卡包导出功能，通过微信面对面发文件即可秒级无损转移。
