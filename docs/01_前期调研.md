# 01 前期调研：孤独症低龄儿童沟通障碍特征与PECS临床证据

## 一、研究背景与孤独症低龄儿童沟通障碍特征

孤独症谱系障碍（Autism Spectrum Disorder, ASD）是一种神经发育障碍，其核心临床特征之一是严重的**社会交往和言语/非言语沟通障碍**。在3—8岁低龄ASD儿童群体中：
- 约 **25%~50%** 的儿童在学龄前仍处于**完全无口语**或**口语极其有限（仅有零星仿说或非功能性单字）**的状态；
- **共同注意（Joint Attention）**严重受损，难以通过眼神对视、手指指向或面部表情表达基本生理与情感需求；
- 难以发起自发性沟通（Spontaneous Initiation），极易因生理需求或情绪无法被成人理解而诱发自伤、攻击他人或严重尖叫等**挑战性行为（Challenging Behaviors）**；
- 视觉加工通道普遍显著优于听觉通道（视觉优势学习者），对图示、图像具备较强的知觉识别与记忆能力。

因此，引入**辅助与替代沟通（Augmentative and Alternative Communication, AAC）**系统，是国际公认改善ASD儿童早期语言和行为问题的核心循证干预策略。

## 二、两份核心文献的深度临床实证分析

本项目严格参考并结合了国内外两份权威实证研究文献作为产品设计与系统演化的循证医学基础：

### 1. 文献一分析：《Picture Exchange Communication System (PECS) Implementation Program for children with autism spectrum disorder》（Tamanaha et al., 2023, CoDAS）
- **研究方案与样本**：评估了一项针对ASD儿童的PECS标准化临床实施方案（24次干预疗程，结合家庭照料者全程高黏性协同参与，家庭依从性高达96%）。
- **六阶段递进达成率**：
  - **第I阶段（物理交换/如何沟通）**：**100%** 儿童达成。儿童学会主动拿起实物卡片递给沟通伙伴以换取强化物；
  - **第II阶段（增加距离与坚持度）**：**100%** 儿童达成。儿童学会在不同距离、不同沟通伙伴面前坚持寻找卡片并完成交换；
  - **第III阶段（图片辨别）**：**100%** 儿童达成。儿童能从2张及以上卡片中准确辨别出目标卡片；
  - **第IV阶段（句子结构构建）**：**82%** 儿童成功达成。儿童能够使用“我想要（I want）”起始卡与具体物品卡组合成**句子条（Sentence Strip）**完成整句表达；
  - **第V阶段（回答“你想要什么？”）**：**64%** 儿童达成。儿童开始具备应对式沟通反应；
  - **第VI阶段（自发评论与评价）**：仅有 **19%** 儿童达成。儿童对环境刺激（如“我看见”、“我听见”）进行主动评价的能力依然受限。
- **对本项目的核心启示**：
  1. **句子条（Sentence Strip）是语言结构化的关键门槛（82%成功率）**：电子PECS必须保留并优化“句子条”操作，强化从单卡交换向句式结构构建的过渡。
  2. **第V、VI阶段衰减率高的根源**在于传统教学缺乏**动态情境支持**与**多模态反馈**：电子系统需引入**情境感知推荐**与**即时听觉语音输出（Speech Output）**，降低儿童从“需求表达”跨越到“应答与评论”的认知负荷。
  3. **家庭照料者的全程深度参与是干预成功的核心驱动力（96%依从率）**：系统必须提供极其便捷的“家长/特教老师端”，便于家庭日常生活中的即时拍摄制卡与数据跟踪。

### 2. 文献二分析：《The Use of the Picture Exchange Communication System to Improve Expressive Language Skills in Non-Verbal Children with Autism: A Systematic Literature Review》（Fahliza et al., 2024, Global Journal）
- **系统综述规模**：基于12项严谨同行评议研究、共计158名无口语/低口语ASD儿童样本的系统性文献综述（SLR）。
- **核心结论**：
  - **提升言语表达与言语请求（Vocal Mands）**：PECS能显著增加无口语儿童的发音尝试、词汇储备和功能性提要求能力；
  - **显著降低问题行为**：多项纳入研究证实，随着PECS沟通通道的建立，儿童因沟通受挫导致的攻击性行为（Aggressive Behaviors）和发脾气频率呈统计学显著下降；
  - **高科技/电子化AAC（High-Tech AAC / Tablet PECS）的显著优势与考量**：
    - 电子设备具有更高的便携性，并能提供恒定且清晰的**语音输出（Vocal Output / Speech Generating Device, SGD）**，对激发口语模仿具有传统纸质卡片不具备的双重多模态刺激；
    - 但文献明确指出：电子系统必须能够**根据儿童个体的发育水平定制视觉材料**（从实物照片平滑过渡到抽象线描图），并强调**家长与特教老师的主动介入与设置可控性**。

## 三、传统物理PECS卡片的现实痛点

| 评估维度 | 传统纸质魔术贴PECS手册 | 数字化/电子PECS（本项目方案） |
| :--- | :--- | :--- |
| **便携性** | 沟通册厚重笨重，外出携带不便，常遗漏在车上或家中 | 手机/平板/小程序随身携带，随时随地可用 |
| **维护与丢失** | 魔术贴卡片易脱落、沾灰受潮、被儿童撕扯丢失，补做繁琐 | 云端/本地持久化保存，卡片永不磨损丢失 |
| **扩充成本** | 需打印、裁剪、过塑、剪圆角、粘贴魔术贴，制卡耗时数天 | 手机随手拍照+输入文字，5秒即可生成标准沟通卡 |
| **感官反馈** | 仅有视觉与触觉反馈，无即时声音输出 | 内置高保真TTS离线语音，点卡/句条即时朗读，强化口语磨耳朵 |
| **数据记录** | 依赖特教老师或家长纸笔手动打勾记表，漏记率极高 | 自动记录每次沟通时间戳、所选卡片、情境，生成可视化趋势图 |
| **情境适应性** | 面对数百张卡片需频繁翻页查找，儿童易失去沟通耐性 | 智能情境感知（早餐、课堂、游戏、如厕），高频卡秒级推至首屏 |

## 四、调研结论与系统设计原则

1. **坚持循证干预原则**：严格遵循PECS从“单卡识别”到“句子条组装（我想要 + 物体）”的认知递进路径，不随意破坏经过临床验证的交互范式；
2. **严守伦理与边界红线**：
   - **不替代专业AAC医学评估**：在系统显要位置明确声明，电子PECS作为日常辅助沟通工具，需配合临床言语治疗与特教康复训练；
   - **语音家长可控**：支持调节音量、音调、发音人及语速，避免过敏或机械杂音刺激ASD儿童听觉超敏；
   - **数据本地优先（Local-First）**：保护特殊儿童个人生物信息与家庭隐私，离线完全可用。
