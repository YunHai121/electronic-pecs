# 05 产品实现：关键技术、核心算法与工程落地

本项目采用“Web H5 + 微信小程序”双栈同构架构，确保无论是作为标准PWA网页应用、平板原生应用，还是作为微信小程序运行，都能保障极致的性能、离线可用性与顺畅的触觉交互体验。

## 一、系统技术栈选型与架构分工

| 层次 | 技术选型 | 选型考量与优势 |
| :--- | :--- | :--- |
| **表现层 (UI/UX)** | HTML5, CSS3 (Modern Flex/Grid), Vanilla ES6+ / 微信小程序原生WXML+WXSS | 零第三方重型框架包袱，极致轻量，百元低端安卓机/老旧平板秒开，无内存泄漏 |

## 二、核心模块算法与技术实现解析

### 1. 拖拽与触控双兼容句子条构建机（Drag & Drop / Touch Engine）
在低龄ASD儿童的交互过程中，部分儿童精细动作弱，无法持续长按拖拽，而部分儿童已习惯物理卡片的拖放动作。为此，系统实现了**“点选加入”与“自由拖拽”**无缝兼容的交互引擎：
- **拖拽状态机**：监听 `dragstart`, `dragover`, `drop` 以及移动端 `touchstart`, `touchmove`, `touchend`。
- **自动占位与动画吸附**：卡片悬停在句子条上方时，出现虚线占位符；松手瞬间触发轻微缓动动画。
- **降级保护**：儿童只需单击任意卡片，卡片便会自动“飞入”句子条末端；点击句子条内的卡片即可退回。

### 2. 离线TTS语音引擎与家长个性化可控调参
```javascript
// TTS核心封装逻辑示意
function speakSentence(cards, settings) {
  if (!('speechSynthesis' in window)) return;
  window.speechSynthesis.cancel(); // 停止当前正在播放的发音
  
  // 拼接规范朗读文本: 如 "我想要" + "苹果" + "谢谢"
  const fullText = cards.map(c => c.text).join(' ');
  const utterance = new SpeechSynthesisUtterance(fullText);
  
  utterance.lang = 'zh-CN';
  utterance.rate = settings.rate || 0.85;   // 专为ASD儿童设计的微慢语速（默认0.85倍）
  utterance.pitch = settings.pitch || 1.0; // 柔和自然音调
  utterance.volume = settings.volume || 1.0;
  
  // 逐字/逐卡视觉动画联动
  utterance.onboundary = (event) => {
    highlightCardAtIndex(calculateIndex(event.charIndex));
  };
  
  window.speechSynthesis.speak(utterance);
}
```

### 3. 智能情境感知推荐算法（Context Recommendation Algorithm）
为了解决传统PECS“面对上百张卡片翻找困难”的根本痛点，系统研发了基于**“时段感知 + 场景规则 + 历史交互频次衰减”**的混合推荐算法模型。

**推荐得分公式**：
$$Score(C_i) = \alpha \cdot Match(Tag_{context}, C_i) + \beta \cdot Match(TimeSlot, C_i) + \gamma \cdot \sum_{k=1}^N e^{-\lambda (t_{now} - t_k)}$$

- **第一项（情境匹配度）**：当前选定情境（如“进餐/点心”）与卡片标签的交集权重（$\alpha = 0.5$）；
- **第二项（时间槽匹配度）**：系统自动获取当前设备时间（7:00-9:00对应早餐、12:00对应午餐、15:00-16:00对应下午加餐/户外游戏、20:00-21:30对应洗漱就寝），时间槽匹配权重（$\beta = 0.3$）；
- **第三项（历史频次时间衰减）**：该儿童过去7天内使用该卡片的次数按时间指数衰减（$\gamma = 0.2$），高频使用的卡片自动获得优先置顶。

### 4. 拍照制卡与Canvas图像压缩流水线
家长随手拍摄的实物照片通常为 3MB~8MB 的超高清图片，若直接存入本地将迅速耗尽浏览器存储。系统构建了前端轻量压缩流水线：
1. `FileReader` 异步读取图片为 `Image` 对象；
2. 计算图像中心裁剪区域，提取 $1:1$ 正方形比例；
3. 绘制到隐藏的 $256 \times 256$ 尺寸 Canvas 节点；
4. 导出为高压缩比 WebP 或 JPEG (品质系数 0.82)，单张图片体积降至 **15KB 左右**，清晰度完全满足屏幕展示，且保证应用加载毫秒级响应。

### 5. 沟通行为数据分析与量化追踪引擎
系统在儿童每次成功点击“朗读”句子条时，自动记录一条不可篡改的日志单元：
```json
{
  "logId": "log_1732103400123",
  "timestamp": 1732103400123,
  "timeStr": "2026-11-20 20:30:00",
  "context": "snack",
  "sentence": ["我想要", "草莓", "谢谢"],
  "cardIds": ["core_want", "custom_food_09", "core_thanks"],
  "cardCount": 3,
  "independent": true
}
```
通过聚合算法，系统实时计算：
- **今日/本周沟通频次趋势**（折线图展现儿童沟通意愿成长趋势）；
- **高频表达 Top 5 榜单**（帮助家长和老师掌握当前最有效的生活强化物）；
- **情境分布雷达/环形图**（评估儿童在居家、课堂各情境下沟通能力的均衡性）。

### 6. 数据本地优先与离线卡包安全架构
- **零外部隐私泄露**：不强制依赖任何中心化远程服务器，卡片照片和患儿姓名、日志均加密驻留于终端沙箱；
- **全量卡包导入/导出**：提供标准规范的 `.json` 离线卡包打包机制，方便特教老师在机构配置好整套词库后，一键导出发送给家长，家长在手机上一键导入即可同步使用。
