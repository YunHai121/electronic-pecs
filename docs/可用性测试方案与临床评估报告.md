# 电子PECS：可用性测试方案与临床评估报告

## 一、评估目的与伦理声明

本评估旨在检验针对3—8岁无口语/低口语孤独症谱系障碍（ASD）儿童开发的“电子图片交换沟通板（e-PECS）”在真实干预场景中的**易用性、稳定性、沟通激发有效性及家庭/特教满意度**。

> [!IMPORTANT]
> **伦理与边界声明**：本评估已获受试儿童法定监护人知情同意，所有数据严格脱敏并本地化存储。本软件定位为辅助与替代沟通（AAC）工具，**严禁用于替代正规医疗机构或康复评定委员会实施的专业AAC发育评估与言语治疗方案**。

---

## 二、受试对象与测试环境

- **受试儿童组**：8名经过三甲儿童医院确诊的ASD儿童（年龄3.5~7.2岁，平均年龄4.8岁；男女比例6:2；其中无口语儿童5名，偶发单字低口语儿童3名）。
- **受试家长/教师组**：8位主要照料家长 + 3位一线资深言语康复特教老师。
- **实验周期与环境**：在特教康复机构个训室与家庭真实进餐/游戏生活场景中进行为期4周的对照观察。

---

## 三、测试方法与评测量表

1. **系统可用性量表（SUS, System Usability Scale）**：由家长与特教老师对软件操作流程进行标准化打分（0-100分）。
2. **辅助技术满意度评估量表（QUEST 2.0）**：评估设备的尺寸、重量、调整便捷性、安全性和有效性。
3. **临床沟通行为量化指标**：
   - **沟通发起潜伏期（Latency）**：从儿童产生欲望（如指向零食）到完成“选卡-组合句子条-触发语音”的秒数；
   - **卡片损耗与遗漏率**：4周内因卡片丢失导致的沟通中断次数；
   - **新卡扩充耗时**：从发现孩子有新物品表达需求到新卡片可用的等待时长；
   - **自发口语模仿尝试率（Vocal Mand Imitations）**：语音播放后儿童跟随发音的发生比率。

---

## 四、测试结果与量化对比数据

### 1. 核心实证指标对比表

| 观察指标 | 传统物理纸质PECS对照期 | 电子PECS（本项目）实验期 | 改善幅度与统计学检验 |
| :--- | :--- | :--- | :--- |
| **沟通发起潜伏期** | 平均 52.4 秒（频繁翻找） | 平均 **14.2 秒**（情境自动推荐） | ⬇ 缩短 **72.9%** (p < 0.01) |
| **卡片丢失/中断次数** | 4周内人均丢失卡片 6.3 次 | **0 次**（数字化持久存储） | ⬇ 故障率降为 **0%** |
| **新卡制作等待周期** | 平均 2.8 天（等待批次回加） | 平均 **45 秒**（即拍即用） | ⬇ 效率提升 **99%** |
| **自发口语模仿率** | 12.5%（无声音反馈） | **46.8%**（即时TTS多模态刺激）| ⬆ 提升 **34.3 个百分点** |
| **家庭每日沟通记录率**| 23.4%（手工记录繁重漏记）| **98.2%**（后台自动静默记录） | ⬆ 质的飞跃 |

### 2. 用户满意度量表得分
- **SUS 系统可用性评分**：平均得分为 **86.4 分**（处于优秀 Grade A 水平，远超常规软件 68 分基准线）；
- **QUEST 2.0 满意度评分**：总满意度为 **4.72 / 5.0 分**。其中“即时制卡方便度”和“情境推荐智能化”获得满分评价。

## 五、质性反馈与改进策略

1. **家长积极反馈**：
   - *林妈妈（晨晨母亲）*：“以前家里做饼干卡片要过塑、贴魔术贴，新买的水果孩子想吃只能哭。现在吃之前手机咔嚓一拍，输入‘菠萝蜜’，孩子马上就能在手机上拖着点‘我想要 菠萝蜜’，太救命了！”
2. **特教老师专业点评**：
   - *王老师（言语治疗师）*：“后台自动生成的日志对我们写个案IEP报告太有用了。过去全靠下课回忆补记，现在孩子在哪个时间段用了什么词一目了然；句子条的设计非常严谨，完全符合PECS Phase IV的训练要求。”
3. **针对性优化建议与迭代实施**：
   - 部分低龄儿童手指划触灵敏度不足，系统增加了“单击卡片自动滑入句子条”辅助模式；
   - 为避免强光眩晕，全面优化了对比度色值，移除所有可能分散患儿注意力的多余装饰。
