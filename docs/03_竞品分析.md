# 03 竞品分析：现有AAC方案评测与差异化破局

为找准本项目的技术与产品定位，我们对国内外主流的无口语/低口语儿童辅助沟通方案进行了多维度的横向与纵向竞品评测。

---

## 一、主要竞品类型与对象介绍

1. **传统物理PECS手册（Pyramid Educational Consultants 官方体系）**：
   - 依赖活页夹、魔术贴条和塑封层压卡片。是全球特教领域的“金标准”工具，但在便携性与词库扩充上面临不可逆的物理瓶颈。
2. **国际高端高科技AAC软件（Proloquo2Go / TouchChat HD）**：
   - 欧美市场代表性成熟产品，支持极深层级的词汇矩阵与动态键盘，功能强大。
   - **痛点**：仅限iOS平台、购买售价高昂（单次买断售价常超 249 美元或高昂月度订阅）、专为英语语法（屈折变化、时态）设计，对中国本土语境、中文分词及拼音支持极弱，且系统复杂度极高，极易造成认知水平较低的ASD低龄幼儿产生“感官过载”（Sensory Overload）。
3. **开源跨平台AAC（Cboard）**：
   - 基于Web的开源AAC，支持多语言和网页访问。
   - **痛点**：缺乏针对ASD儿童专门设计的PECS“句子条”标准工作流，没有基于生活情境的高频动态推荐算法，国内弱网环境下离线加载卡顿，且缺乏移动端拍照即时制卡能力。
4. **国内同类小程序与商业AAC App**：
   - 国内目前虽有部分沟通板工具，但大多为静态九宫格点读机模式，缺乏严格遵循PECS Phase IV“我想要 + 目标词”的句式生成机制，且普遍存在强制高额会员订阅、数据强依赖云端服务器导致的儿童隐私泄露风险。

## 三、本项目的核心竞争优势与创新定位

```
               [ 认知适应性 (低认知负荷 / 零感官过载) ]
                                 ▲
                                 │       ★ 本项目 (电子PECS)
                                 │     (本土化/轻量/情境推荐/本地优先)
                                 │
                 传统物理PECS    │
                                 │
 ◄───────────────────────────────┼──────────────────────────────►
 [ 纸质静态维护成本高 ]          │             [ 高度复杂矩阵系统 ]
                                 │           (Proloquo2Go / LAMP)
                                 │
                                 │
                                 ▼
               [ 数字化交互与多模态扩展能力 ]
```

1. **情境感知高频推荐引擎（创新点 1）**：
   - 告别在几百张卡片中翻页查找的挫败感。系统在早晨自动推荐“牛奶、面包、洗脸”，在户外自动推荐“滑梯、秋千、喝水”，使平均沟通发起潜伏期缩短 **70%** 以上。
2. **离线高保真语音输出与家长可控（创新点 2）**：
   - 彻底脱离网络束缚，在公园、地铁、特教教室内无网依然流畅发音；
   - 针对孤独症儿童常伴有的听觉超敏特性，提供语速减慢（0.5x~1.0x）、音调平缓以及纯正自然音发音人切换，甚至支持录入家庭熟悉声音。
3. **闭环行为追踪与可视化个案报告（创新点 3）**：
   - 每次儿童把卡片拖入句子条并朗读，系统自动沉淀为一条结构化沟通事件，直观展现儿童从“单字提要求”向“双词/动宾句”发展的跃迁轨迹，成为特教老师IEP评估的客观量化支撑。
4. **轻量生态与极低使用门槛**：
   - 基于 Web 标准与微信小程序生态，无需购买昂贵外设，普通百元安卓机或旧 iPad 即可丝滑运行，真正普惠每一个特殊儿童家庭。
