# 声动星河 · 电子PECS智能辅助沟通系统 (e-PECS)

> **面向孤独症低龄儿童的电子图片交换沟通板设计与可用性研究**
>
> 🎯 **对象**：3—8岁无口语/口语有限ASD儿童 + 家长/特教老师  
> 💡 **痛点破局**：传统PECS卡片易丢、难扩展、不便携、缺乏即时声音反馈  
> 🧩 **核心功能**：拖拽图片卡→标准化句子条→TTS语音输出；拍照做卡、分类管理、使用记录；智能情境高频推荐  
> 🔧 **技术架构**：微信小程序 + Web-App (PWA) + 本地图库 + 离线TTS语音 + 离线数据包 + 本地优先存储  
> 🌟 **核心创新**：情境感知智能推荐 + 离线高保真语音 + 沟通行为全自动量化记录  
> ⚠️ **边界规范**：不替代专业AAC医学评估，语音家长可控，数据本地优先零隐私泄露

## 🚀 快速启动与体验指南

### 方式一：直接在浏览器中运行 Web 原型（支持 PC、iPad、触屏手机）
1. 双击打开 `web-app/index.html`；或者在当前目录下使用 Python 启动轻量本地服务器：
   ```bash
   cd web-app
   python -m http.server 8080
   ```
2. 打开浏览器访问 `http://localhost:8080`；
3. **主要功能体验**：
   - **儿童沟通**：点击或拖拽卡片至顶部“句子条”，点击“🔊 朗读整句”，体验逐卡高亮与自然语音播放；
   - **情境推荐**：切换顶部情境（如“进餐点心”或“桌面教学”），体验推荐栏卡片实时重排；
   - **家长管理**：点击右上角“家长/特教中心”，通过儿童防误触算术题，即可体验**手机随手拍照做卡、查看沟通行为数据折线图、导出离线卡包**。

### 方式二：导入微信开发者工具
1. 打开“微信开发者工具”，选择“导入项目”；
2. 目录选择 `miniprogram` 文件夹，AppID 可选择“测试号”；
3. 即可在微信模拟器中体验轻量级小程序。
